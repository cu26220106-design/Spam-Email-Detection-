# Project Synopsis

## Title
Spam Email Detection Using Machine Learning

## Objective
To build a machine learning model that automatically classifies an email as spam or legitimate (ham).

## Technology
Python, Pandas, Scikit-learn, TF-IDF, Logistic Regression, Matplotlib.

## Methodology
Email text is cleaned through standard vectorization, converted into TF-IDF features, and classified using Logistic Regression. The dataset is divided into training and testing subsets, and performance is measured using standard classification metrics.

## Expected Output
The system displays whether a new email is **SPAM** or **HAM (Not Spam)** along with a confidence score.

## Future Scope
The system can be extended with a larger real-world dataset, additional NLP preprocessing, deep learning models, multilingual support, and deployment as a web application.
